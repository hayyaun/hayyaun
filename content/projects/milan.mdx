## Overview

Milan is a creative studio website. This case study focuses on translating a visual identity into a responsive browsing experience that makes the studio’s work easy to explore.

## Role and challenge

My role was frontend implementation: translating the visual direction into responsive layouts, reusable interface elements, and interaction details. The main challenge was preserving the character of the design while keeping navigation and project content clear across screen sizes.

## Implementation

I organized the interface around a small set of reusable layout and typography rules. Images established the hierarchy, while interaction details supported navigation without delaying access to the work. Responsive behavior was designed around content needs rather than a scaled-down desktop composition.
